### 🎯 **執行標準與規則確認**

#### **【基礎標籤格式要求】**

1.  **底線替換：** 所有 Danbooru 標籤中的底線 (`_`) 將全部替換為空格。
2.  **關鍵名詞標註：** 重要的名詞或特殊概念必須使用以下格式標註：**(中文翻譯)** (小寫英文名詞) 。這些標註將被植入描述文字中。
3.  **標籤類型明確：** 必須明確區分並標示：**(主題關鍵要素標籤)** / **(主題限定專屬) 標籤**。
4.  **細節完整性：** 必須詳盡轉化每個視覺要素，不可遺漏任何出現的細節。
5.  **語境植入：** Danbooru 標籤 (英文+中文翻譯) 不會被獨立羅列，而是會被 **直接融入** 描述文字中。
6.  **混合描述：** 無法標籤化的內容，將採用 **自然語言 + 標籤** 的混合形式描述。

#### **【精細化語意要求】**

| 類型 | 描述要求 | 範例（及標籤） |
| :--- | :--- | :--- |
| **動作/姿態** | 必須標記動作的**品質**和**行為狀態**。 | 輕柔地捧著 (gently cradling) / 猛烈地疾跑 (aggressively sprinting) |
| **外型特徵** | 必須盡可能分解到**具體的部位**。 | 黑色長髮 (long black hair) **+ 藍色髮尾** (blue hair tips) / 翠綠色的瞳孔 (emerald eyes) |
| **技術/效果** | 必須標記**效果本身**或**生成品質**。 | 高調照明 (high key lighting) / 電影級景深 (cinematic depth of field) |
| **構圖** | **必須提供完整的英文版描述**，並在中文描述中輔以對應標籤。 | *（詳見最終輸出結構）* |
