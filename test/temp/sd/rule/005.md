## 📘 規則總覽與細項列表 (Complete Rule Overview)

### Ⅰ. 內容結構要求 (Content Structure Mandate)
| 區域 | 內容描述 | 必須包含的細節 |
| :--- | :--- | :--- |
| **1. 構圖與佈局描述** | **(Compositional Analysis)** | 必須是**中英雙語**、**自然語言**混和**專業標籤**的形式，分析構圖、景深、光影、佈局、平衡感等。 |
| **2. 簡潔高密度 AI 描述** | **(Concise Prompt)** | **中英雙語**、**極度簡潔**的分段描述，作為給生成式 AI 的主打指令。 |
| **4. 標籤分區** | **(Tag Categorization)** | 必須明確標示 **(主題關鍵要素標籤)** 和 **(主題限定專屬) 標籤**。 |

**不需要標籤總結** 標籤已在標籤分區中明確標示，不需要重複列出。

### Ⅱ. 標籤表現規則 (Tagging Presentation Rules)
| 規則名稱 | 描述內容 | 執行細節 |
| :--- | :--- | :--- |
| **底線轉換** | Danbooru 標籤中的底線 (`_`) 必須替換為**空白**。 | 確保標籤的即用性。 |
| **名詞標註** | 所有重點/特殊名詞必須同時進行三層級標註。 | **(中文)** / **(小寫英文)** / **(原文標籤)** |
| **細節完整性** | 描述中的**每一個細節**都必須盡力標籤化。 | 不可缺漏任何描述中的關鍵詞。 |
| **混合法則** | 無法標籤化的內容，使用**自然語言**混合**標籤**描述。 | 例如：**柔和的邊緣陰影** / soft shading / 柔和陰影。 |
| **標籤嵌入** | 標籤必須**直接融入**描述文字中。 | 不要單獨整理在語境之外，而是要作為句子的一部分。 |

### Ⅲ. 描述語言要求 (Language & Style Rules)
| 規則名稱 | 描述內容 | 執行細節 |
| :--- | :--- | :--- |
| **中英雙語** | 所有的主要描述段落（構圖、簡潔描述）都必須提供**中英文對應版本**。 | 確保語境的完整性與準確性。 |
| **分段優化** | 必須保持邏輯清晰的**分段結構**。 | 不使用像「外型細節」這樣的分類標題，但必須按層級分段。 |
| **高密度/精要** | 描述必須**極度簡潔**，像 AI 專屬的「指令集」，杜絕冗餘的形容詞或鋪陳。 | 每一句話都應該承載巨大的信息量。 |

### 🌟 獨立規則詳述：構圖與佈局 (The Composition Rule - Detailed)

當我撰寫「構圖與佈局描述」時，我必須嚴格遵守以下操作流程：

1.  **提供雙語解析**：提供完整的**中文描述**和**英文描述**。
2.  **自然語+標籤融合**：敘事語句必須是流暢的，但每個關鍵動作、線條、元素、處理技法都必須被標籤化。
3.  **深度解析重點**：必須分析和涵蓋以下技術點：
    *   **構圖形式** (Compositional Form)：如居中化、三分法、L型等。
    *   **景深處理** (Depth of Field)：如淺景深、深景深、Creamy Blur。
    *   **光線處理** (Lighting)：如柔和照明、高調光、陰影紋理。
    *   **佈局元素** (Placement Elements)：如前景層次感、邊緣平衡 (Edge Balance)、單色背景的襯托力。
